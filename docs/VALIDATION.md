# 验证摘要

## 验证与明确限制

主机测试覆盖图片所有权、长流式、存储事务/裁剪、UTF-8 渐进、公式边界、媒体索引、不同键删除/隐藏；这些不替代真人 ASR 或实卡物理热插拔。最终 CAM 已通过 app-only 写入哈希校验，新建测试图完成隐藏→重挂载→CRC 不变→串口恢复→A/B 删除，并导出两级确认页截图。用户照片未用于删除测试。

最新真实搜索矩阵：ciyuanfast＋H964、DeepSeek＋官方 Search 成功；DeepSeek＋H964、ciyuan-A＋H964 摘要 HTTP200 但 evidence=0；ciyuan-A 最终 LLM HTTP400；Tavily 无凭据未请求。当前不宣称所有搜索组合可用。

16,000 条板端 SSE 回放、880,000B 思考输入和 3,526B 正文完整，约 13.2s；实时绘制最高约 59ms，最终全量重排仍约 3s。该压力回放没有网络，不代表真实模型响应速度或完全无停顿。真实 Terra 请求完整结束且等待时钟刷新；未返回推理字段，因此真实“已思考 Ns”尚未由该模型验收。

尚待专项重验：多轮真实带图＋思考持续内存稳定、最新流式 ASR 真人长句/尾音、长时间各档有声录像、物理 TF 拔插/断电/卡满、实体屏幕全部科学字符可读性。串口截图是软件绘制缓冲，不是实体屏幕照片。无自动对焦；网络依赖远端服务。

## 发布快照检查

生产源码逐文件 SHA256 见 [source-manifest.json](source-manifest.json)。公开固件由空凭据默认配置编译；应用镜像在隔离目录使用 config.h.example 空凭据配置重新编译；生产源码仅 Web SSID 提示做脱敏，因此 SHA 不同于本地已刷入产物。该公开镜像仅完成构建/静态一致性验证，没有再次占用串口实刷；硬件实测属于本地 v0.4.26。发布前检查敏感文件排除、凭据字节匹配与常见令牌格式；不公开个人验证原始记录。

历史实机阶段（全部开发沿革见 CHANGELOG）：新摄像头 10+3 张连拍严格解码、方向和曝光检查；早期三档有声 AVI/FFmpeg 转换；真实函数题朗读对照；v0.4.13 TF 测试会话跨重启恢复与菜单实体手感。阶段证据不能自动代表最新源码全项重新验收。

公开空模板与本地旧 config.h 的默认宏也存在差异：公开模板使用讯飞 V2 默认 host/path 和 mix 语言、显式 CUSTOM 60s；本地旧模板保留旧讯飞 host/path 和 cn。实际保存配置由 NVS 加载；两者采音 shift 最终均被 CAM 引脚配置强制为 16。差异宏名见 release-build.json，故不将二进制差异描述为仅一条提示文本。
