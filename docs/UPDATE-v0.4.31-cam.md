# v0.4.31-cam 源码更新

本次从 v0.4.26 整合到 v0.4.31，保留 MIT；依赖与字体仍遵循 THIRD_PARTY_NOTICES。完整开发沿革见 CHANGELOG，公开源码不含账号、个人会话、照片、录音或 Flash 备份。

## 当前行为

- CUSTOM IAT 边采音边上传，并在录音过程中显示服务端增量结果；需要支持增量 IAT 的服务。只返回最终结果的旧服务不会因此产生逐字结果。保留其他 ASR 选项。
- 首次 ASR 连接等待时，每 100 ms 刷新采音任务发布的真实 RMS；官方 V2 也使用工作任务建立连接，主界面继续更新时间。
- 单击 C 删除一个 UTF-8 字符；双 C 仅请求清空全部语音草稿，A 确认后执行，B 取消，C 取消确认并继续删字。保留候选照片。确认提示在主界面重绘时保持显示。最后一个字已经删完时，不再弹出多余确认或取消选图。
- MENU 的二值设置短按 A 直接切换并保存，包括识别语言、界面语言、思考显示、拍照/语音提问、仅拍照、相机预览及 OFF/AUTO 搜索。普通二档思考开关也直接切换；DeepSeek 四档思考以及视频分辨率、ASR 服务商、搜索服务商、模型/Provider 列表继续 B/C 编辑。
- 修复 32KB 历史窗口与 70KB 长思考记录读取，保留未加载前缀并阻止损坏记录覆盖；采用 32 位 JSON 字符串长度，显示未保存状态。
- 优化数学/化学分式与角标、Markdown 混排、灰色思考缓存及连续滚动余量。流式识别/草稿只重排变化的末尾；角色、原文、思考状态、语言、宽度、照片变更会使历史排版缓存失效。空闲到第一条增量文字也复用主界面已建立的排版。

## 验证和限制

公开空配置构建通过：Arduino ESP32 3.3.8，程序 2,852,363 字节（90%），静态全局内存 79,140 字节。编译通过不代替实体硬件验收。

主机回归通过：70KB 单条长记录、190 条反复保存/淘汰及损坏归档保护；108 行公式/Markdown 几何与状态测试；15 组循环/绘制节奏滚动；IAT 快照、尾音和最终 ACK；3 秒等待期间音量更新；双 C 确认/取消与长重绘；历史缓存与完整重排参考在 100 组变化中一致。100 条未变历史在 100 次增量更新中没有重复解析。主机字体桩不等于实体字体清晰度。

CAM 的真人首次录音已确认音量立即跳动、文字持续更新；串口记录没有 I2S/缓冲溢出，上传字节数与采集一致并收到最终 ACK。双 C 确认、B/C 取消、A 清空且不发送问题、最后一字、单 A 中英文切换/恢复、多值亮度编辑均在 CAM 和原版开发设备上执行了真实串口按键回归。

同一原版 563 行会话的草稿回执测量，旧实现为 953/875/797 ms，缓存后两轮为 47/63/47 与 109/47/47 ms（含第一条草稿）。这是板端排版响应，不能等同于端到端 ASR 延迟。首次 TLS/WebSocket 连接和上游识别仍需时间；当前不能保证每个字都即时返回。

搜索回归覆盖受限规划、HTTP 错误、补搜与正文提取等主机场景。真实服务与模型仍有兼容差异，没有把全部搜索 Provider 都称为实机验收通过。本次源码提交没有部署服务器。
